# Sample Projects

This directory contains loadable `lwrclpy Web Node Editor` project JSON files.

## How to run

1. Start the editor from the `lwrclpy_web_node_editor` directory:

   ```bash
   .venv/bin/python main.py --host 127.0.0.1 --port 8765
   ```

2. Open `http://127.0.0.1:8765`.
3. Click `Load` and select one of the JSON files in this directory.
4. Click `Run` or `Run For`.

Each sample embeds the media needed for a first run, so it can run immediately after loading. Image samples contain an embedded image. Video samples contain an embedded base frame that the browser animates during `Run`. You can still replace the embedded media by using the `Load Image` or `Load Video` button on the input node.

## Projects

- `01_image_edge_topic_graph.json`: embedded image input, grayscale conversion, edge-strength filter, image display, edge-strength graph, and `/sample1/edge_strength` topic output.
- `02_video_motion_topic_graph.json`: embedded video-frame input, frame-difference motion mask, motion overlay display, motion-score graph, and `/sample2/motion_score` topic output.
- `03_image_color_balance_topic_graph.json`: embedded image input, contrast stretch, red-balance processing, display, red-index graph, and `/sample3/red_index` topic output.
- `04_video_low_light_colormap_topic_graph.json`: embedded low-light video-frame input, gamma brightening, pseudo thermal colormap display, luminance graph, and `/sample4/luminance` topic output.
- `05_image_crop_mosaic_topic_graph.json`: embedded image input, center crop, mosaic privacy filter display, mean-intensity graph, and `/sample5/mosaic_mean` topic output.

## Regenerate

The JSON files are generated by `generate_sample_projects.py`:

```bash
.venv/bin/python samples/generate_sample_projects.py
```
